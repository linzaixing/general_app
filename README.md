# 榫卯匠造

`general_app` 仓库 `feature/art` 分支上的应用：一款以中国传统榫卯为主题的 3D 木工解谜游戏。

每一关给你一块方木和一只卯眼。你要切掉多余木料，把榫头修到与卯眼严丝合缝，再拼合、评星。

> 说明：本应用为独立实现，玩法参考榫卯题材解谜，但代码、模型、贴图、名称均为原创，未使用任何第三方游戏的素材。

## 玩法

- **看卯眼**：右侧是带孔的卯眼，孔的形状就是你要做出的榫头。
- **切割**：在木料表面拖动，沿拖动的方向锯掉一整片木料。
- **凿除**：轻点木料的某个面，凿掉那一格。
- **旋转**：双指拖动旋转，双指捏合缩放；也可切换到「旋转」工具单指旋转。
- **拼合**：当剩余木料与卯眼完全吻合时自动判定成功。
- **评星**：步数不超过目标步数得三星，超出 3 步内得两星，否则一星。

## 内容

- 3 个章节、13 个关卡，从直榫、燕尾榫到粽角榫、走马销。
- 8 类榫卯图鉴，通关对应关卡后解锁，含做法说明。
- 6 个木作印记（成就）。
- 关卡顺序解锁，记录每关最佳星级。
- 本地存档，无账号、无联网、无任何权限申请。

## 操作提示

- 单指在木料上拖动 = 切割；轻点 = 凿掉一格。
- 双指 = 旋转与缩放（任何时候都可用）。
- 底部可切换「雕刻 / 旋转」、撤销、重置、查看提示。

## 构建

需要 JDK 17 与 Android SDK（platform 37、build-tools 34+）。

```bash
export JAVA_HOME=/opt/sdkman/candidates/java/17.0.15-tem
export ANDROID_HOME=/home/opencode/android-sdk
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

产物：

```
app/build/outputs/apk/debug/app-debug.apk
```

安装：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 技术说明

- Kotlin + Jetpack Compose，minSdk 29 / targetSdk 36 / compileSdk 37。
- 3D 部分为自研软件渲染：透视投影 + 画家算法 + 面法线光照 + 体素环境光遮蔽，全部用 Compose Canvas 绘制，不依赖 OpenGL 或外部引擎。
- 体素模型 4×4×4，木料与卯眼由同一套体素运算生成。
- 存档使用 SharedPreferences，应用不申请任何权限。
